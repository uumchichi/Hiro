# 히로 (Hiro)

여성 전용 온라인 로테이션 소개팅 프로토타입입니다.

1. **프로필**: 닉네임, 태그(종교·반려동물·음식·취미 등), 머리 길이(숏컷/숏단/단머/중단/긴머), **히로 컬러**(핑크 ~ 퍼플 ~ 블루, 옐로는 플라토닉)와 원하는 상대의 머리 길이·히로 컬러 범위. 히로 컬러는 내부적으로 0(온텍)~10(온깁) 값이고, 화면에는 색 이름으로만 보여요.
   - 성향은 히로 컬러로 표현돼요. 히로 컬러는 **기본 비공개**이고, 공개한 사람만 배지 색으로 보여요. 공개하지 않아도 AI가 서로 맞는 사람끼리 매칭해요.
2. **성향 검사**
   - 나의 성향 12문항 (에너지·공감·계획·새로움·표현)
   - **생활 습관(문담피)**: 담배(안 피움/전자담배만/연초), 문신(없음/작은 문신/중간/큰 문신), 피어싱(없음/귀만/얼굴·바디). 항목마다 **"나는?"**과 **"상대는 어디까지 괜찮아요?"**를 따로 받아요.
   - **원하는 상대 성향**: 축마다 "차분하게 들어주는 사람 / 상관없어요 / 대화를 이끌어 주는 사람"처럼 골라요. 나와 비슷한 사람을 원할 수도, 반대인 사람을 원할 수도 있어요.
   - Claude가 대화 성향 유형과 잘 맞는 상대를 분석해요.
3. **대기실 + AI 초대장** (메인)
   - **바로 시작 초대장 ⚡**: 대기실 화면을 켜 두면 "지금 대화할 수 있어요" 상태가 돼요. 서로 조건이 모두 맞는 분들이 모이면(8명, 또는 4명 이상이 20초 넘게 기다리면) AI가 테마를 정해 최대 8명에게 초대장을 보내요. **60초 안에 선착순 4~6명**이 수락하면 바로 시작해요. 관심 테마를 고르면 그 테마로만 초대받아요.
   - **예약 초대장 📅**: 프로필의 **선호 시간대**(요일 × 오전/오후/저녁/밤)가 겹치는 분들에게 "이번 주 금요일 저녁 7시"처럼 시간을 정해 보내요. 접속하지 않아도 받고, 최대 12시간 안에 선착순 4~6명이 수락하면 **예약이 확정**돼요. 그 시간 10분 전부터 입장할 수 있어요. 확정된 세션은 초대받은 사람만 볼 수 있어요.
   - 초대받은 사람들은 모두 서로 조건이 맞아서, 누가 먼저 수락하든 그룹이 성립해요. 마감되거나 무산된 사람은 다음 초대에서 **우선권**을 받아요.
4. **이벤트 세션**: 정해진 시간에 열리는 공개 세션이에요. 신청해 두고, 시작 시간에 입장해 있는 분들끼리 시작해요.
   - **✨ 운영진 기획 이벤트**: 운영자 화면에서 테마 이름·이모지·설명·태그·대화 주제, **날짜·시간**, 라운드 길이, **정원**을 정해 열어요. 이벤트 페이지 맨 위에 따로 보이고, 정원이 차면 마감돼요. 시작 전에는 운영자가 취소할 수 있어요.
5. **1:1 음성 로테이션**: 그룹 안에서 모두가 한 번씩 1:1로 음성 대화를 해요 (LiveKit).
6. **쪽지와 메모**: 대화한 사람마다 쓸 수 있어요.
   - **쪽지 💌**(애프터 신청): 로테이션이 모두 끝난 뒤 **익명으로** 전달돼요.
   - **메모 📝**: 나만 보는 기록이에요. 끝나면 **메모 리포트**로 한눈에 볼 수 있어요.
7. **리포트와 쪽지의 주인 찾기**: 받은 쪽지 개수와 내용을 보고, 그중 **단 하나**만 골라 주인을 확인할 수 있어요.
8. **매칭과 24시간 채팅방**: 서로가 상대의 쪽지 주인을 찾으면 둘만의 채팅방이 열려요. **24시간 뒤 대화 내용과 함께 자동으로 사라져요.** 채팅방에서는 개인 정보 공유를 자제하도록 안내하고(공유에 대한 책임은 운영진에게 없음), 번호는 실제로 만나서 교환하도록 권해요. 전화번호나 메신저 아이디처럼 보이는 내용을 보내면 한 번 더 확인해요.

### 예상 라운드 수 · 시간
- 짝수 인원은 **인원−1 라운드**, 홀수 인원은 한 명씩 쉬어서 **인원과 같은 수의 라운드**예요. 총 시간 = 라운드 수 × 라운드 길이 + 라운드 사이 쉬는 시간.
- 인원이 정해지기 전(초대장, 예약 초대장, 이벤트 카드, 이벤트 대기실)에는 범위로 보여요. 예: "4~6명 · 3~5라운드 · 라운드당 5분 · 약 16~26분"
- 그룹이 정해진 뒤(시작 카운트다운, 확정된 예약)에는 정확한 값과 끝나는 시각을 보여요. 예: "6명 · 5라운드 · 라운드당 5분 · 약 26분 · 오후 9:26쯤 끝나요". 대화 중에도 위쪽에 끝나는 시각이 보여요.

### 매칭 규칙
- **누구와 대화하나**: 성향 조사의 필수 조건(머리 길이, 히로 컬러 범위·옐로, 문담피)이 **서로 맞는 쌍끼리만** 1:1로 대화해요. 그룹 안에서 모두가 모두와 대화하지 않아요.
  - 예: 딥 블루 4명 + 딥 핑크 2명이 서로만 원하면 한 그룹이 되고, 딥 핑크는 4번, 딥 블루는 2번 대화해요. 딥 블루끼리는 만나지 않고, 상대가 없는 라운드는 쉬어요(총 4라운드).
- **그룹이 되는 조건**: 4~6명이고, 그룹 안에서 **각자 최소 2명 이상**(`HIRO_MIN_PARTNERS`)과 대화할 수 있어야 해요. 대화할 수 있는 쌍이 많을수록 좋은 그룹이에요.
- **원하는 상대 히로 컬러 기본값**: 내 컬러를 고르면 반대쪽 범위가 자동으로 추천돼요(예: 딥 블루 → 딥 핑크~핑크). 직접 바꾸면 그 값을 써요.
- **로테이션 일정**: 대화할 수 있는 쌍마다 한 번씩 만나도록 라운드를 짜고, 라운드 수가 가장 적은 일정을 골라요. 모두가 서로 대화할 수 있으면 원형(라운드 로빈) 방식이에요.
- **가산점(양방향)**: 원하는 상대 성향(차분/활발 등)에 얼마나 가까운지. 같은 조건이면 이 점수가 높은 쪽으로 그룹을 짜요.
- AI가 고른 초대 대상·그룹도 서버가 다시 검사해서, 대화 상대가 모자란 사람은 빼요. AI를 쓸 수 없으면 규칙 기반으로 짜요.
- 시작 전 화면에 **"나는 N명과 대화해요 · 총 M라운드 · 약 X분 · 몇 시쯤 끝나요"**가 보여요.

### 💘 직진하기
- **매칭에 실패한 뒤의 마지막 기회**예요. 쪽지 보내기와 쪽지 주인 찾기가 끝났는데 서로 지목이 안 됐을 때 쓸 수 있어요. 받은 쪽지가 없어서 주인 찾기를 못 하는 경우에는 로테이션이 끝나면 바로 쓸 수 있어요. 이미 매칭된 사람은 쓸 수 없어요.
- **쪽지를 보낸 사람 중 1명**에게, 로테이션마다 1번 채팅을 신청해요. 직진은 보낸 사람이 공개돼요.
- 받은 사람은 보낸 사람, 그 사람의 쪽지, 한마디를 보고 **수락/거절**해요. 수락하면 24시간 채팅방이 열려요.
- 거절과 무응답(24시간)은 보낸 사람에게 구분하지 않고 "이번엔 이어지지 않았어요"로 보여요.

### 채팅 · ID · 신고
- 메뉴의 **채팅**에서 열려 있는 채팅방을 모아 봐요. 메뉴에 열린 채팅방 수가 배지로 보여요.
- 모든 사용자는 **공개 ID**(숫자 + 영어 대문자 5글자, 예: `#K7M2Q`)를 가져요. 헷갈리는 0/O, 1/I는 쓰지 않아요. 닉네임 옆에 보이고, 누르면 복사돼요.
- **🚩 신고**는 공개 ID로 접수돼요(채팅방, 채팅 목록, 리포트의 사람 카드). 신고한 사실은 상대에게 알려지지 않고, 운영자 화면의 신고 목록에서 누적 건수와 함께 볼 수 있어요.

### 🎟️ 도키 · 입장권 · 직진러의 증표
- **도키**는 충전하는 화폐예요. 도키를 **🎟️ 입장권**(10도키)이나 **💘 직진러의 증표**(30도키)로 미리 바꿔 써요. 무료로 받은 도키가 먼저 쓰여요.
- **신규 가입 선물**: 입장권 3장 + 직진러의 증표 1개. (이미 가입한 사용자도 처음 지갑을 열 때 받아요.)
- **입장권은 로테이션 1회에 1장**이에요. 그룹에 들어가면 **맡아 두기만** 하고, 첫 1:1 대화가 두 사람 모두 대화방에 있는 채로 **30초 이상 이어지면** 그때 차감해요. 오류, 대화 상대 없음, 시작 전 이탈로 성사되지 않으면 로테이션이 끝날 때 **돌려줘요**.
  - 대기실 입장, 초대 수락, 이벤트 신청에는 쓸 수 있는 입장권이 1장 이상 있어야 해요.
- **직진러의 증표는 직진 1회에 1개**예요. 보낼 때 맡아 두고, 상대가 **수락하면 차감**, 거절하거나 응답이 없으면 돌려줘요.
- **내 지갑**(`/wallet`): 잔액, 도키로 바꾸기, 충전 상품(결제 준비 중), 사용 내역.
- 결제 연결 전이라 운영자 화면에서 **ID로 도키·입장권·증표를 지급**해요. 모든 변동은 내역(ledger)에 남고, 무료·유료 도키를 따로 기록해요(나중에 환불 계산용).
- 지금은 대화방 화면에 두 사람이 모두 있는지로 대화 성사를 판단해요. LiveKit을 연결하면 웹훅으로 실제 음성 연결을 확인하도록 바꿀 수 있어요.

## 디자인: 히로 컬러

히로 컬러를 사이트 색으로 씁니다. **옐로(플라토닉)**, **핑크**에서 **퍼플**을 거쳐 **블루**가 됩니다. 색 값은 `src/lib/compat.ts`의 `SPECTRUM`과 `tgColor()`, 그리고 `src/app/globals.css`에 있어요.

## 실행

```bash
npm install
cp .env.example .env.local   # 키를 채우세요 (비워 둬도 동작)
npm run dev
```

- 사용자 화면: http://localhost:3000
- 운영자 화면: http://localhost:3000/admin
  - **바로 시작 초대장 테스트**: 내 계정으로 대기실 화면을 열어 두고, 운영자 화면에서 **데모 6명 대기실에 넣기** → **⚡ 바로 시작 초대장 지금 보내기**. 초대장이 뜨면 수락하세요. 데모는 몇 초~수십 초 안에 응답하고, 모이면 대화방으로 넘어가요.
  - **예약 초대장 테스트**: 프로필에서 선호 시간대를 넉넉히 고르고 대기실을 열어 둔 뒤, **데모 6명 대기실에 넣기** → **📅 예약 초대장 지금 보내기**. 대기실의 "예약 초대장"에서 수락하면 확정된 예약이 보여요.
  - **이벤트 세션 테스트**: **데모 참가자 10명 추가** → **2분 뒤 시작하는 테스트 세션 열기** → 이벤트 메뉴에서 신청 후 입장.
  - 라운드를 짧게 보고 싶으면 `.env.local`에 `HIRO_ROUND_SECONDS=30`, `HIRO_BREAK_SECONDS=5`를 넣으세요.

여러 사람이 같이 시험하려면 서로 다른 브라우저(또는 시크릿 창)로 접속하세요. 사용자는 쿠키로 구분합니다.

## 키가 없을 때

| 기능 | 키 있음 | 키 없음 |
|---|---|---|
| 성향 분석, 테마 목록, 큰 세션 그룹 나누기 | Claude (`ANTHROPIC_API_KEY`) | 규칙 기반 대체 로직 |
| 1:1 음성 대화 | LiveKit | 타이머와 화면 흐름만 진행 |

Claude 호출이 실패하거나 결과가 이상해도(없는 id, 중복 배정, 인원 초과 등) 서버가 검증하고, 필요하면 규칙 기반 로직으로 대체합니다.

## 구조

```
src/lib/ai.ts          Claude 연동 (구조화 출력 + 서버 측 대체 모델)
src/lib/compat.ts      만남 성향, 원하는 상대 조건, 양방향 궁합 판정, 스펙트럼 색
src/lib/heuristics.ts  규칙 기반 대체 로직, 성향 점수 계산
src/lib/rotation.ts    1:1 로테이션 일정, 현재 라운드 계산
src/lib/questions.ts   검사 문항과 태그 목록
src/lib/store.ts       저장소 (메모리 + .data/hiro-db.json)
src/lib/server.ts      쿠키 사용자, LiveKit 토큰, 화면용 상태
src/app/api/*          API
src/app/{start,quiz,me,lobby,room,admin}  화면
```

## 정식 서비스 전에 할 일

- **본인인증**(PASS 등)으로 여성·성인 확인. 지금은 체크박스로만 확인해요.
- **DB 교체**: 지금은 서버 한 대의 JSON 파일에 저장해요. Postgres(Supabase 등)로 바꿔야 해요.
- **로그인**(카카오/애플), 신고·차단, 대화 중 비상 종료 버튼.
- 서로 선택한 뒤의 **1:1 채팅**.
- 초대장·예약 알림(웹 푸시·카카오 알림톡). 지금은 히로 화면을 켜 둬야 바로 시작 초대장이 보여요.
- 배포 서버 시간대를 `TZ=Asia/Seoul`로 설정하기 (예약 시간 계산이 서버 시간 기준이에요).
