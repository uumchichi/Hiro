# 히로 (Hiro)

여성 전용 온라인 로테이션 소개팅 프로토타입입니다.

1. **프로필**: 닉네임, 태그(종교·반려동물·음식·취미 등), 머리 길이(숏컷/숏단/단머/중단/긴머), 깁텍(0 온텍 ~ 10 온깁, 플라토닉은 별도)과 원하는 상대의 머리 길이·깁텍 범위.
   - 깁텍은 **기본 비공개**이고, 원하면 공개할 수 있어요. 공개 여부와 상관없이 매칭에는 쓰이고, 참가자에게 보이는 글에는 드러나지 않아요.
2. **성향 검사**
   - 나의 성향 12문항 (에너지·공감·계획·새로움·표현)
   - **생활 습관(문담피)**: 담배(안 피움/전자담배만/연초), 문신(없음/작은 문신/중간/큰 문신), 피어싱(없음/귀만/얼굴·바디). 항목마다 **"나는?"**과 **"상대는 어디까지 괜찮아요?"**를 따로 받아요.
   - **원하는 상대 성향**: 축마다 "차분하게 들어주는 사람 / 상관없어요 / 대화를 이끌어 주는 사람"처럼 골라요. 나와 비슷한 사람을 원할 수도, 반대인 사람을 원할 수도 있어요.
   - Claude가 대화 성향 유형과 잘 맞는 상대를 분석해요.
3. **테마 게시판**: 늘 열려 있는 테마 세션(예: 고양이 집사들의 수다, 매운 거 못 먹는 사람들)을 골라 여러 개 신청해 둬요. 테마 목록은 AI 테마 에이전트가 이용자들의 태그 분포를 보고 만들어요.
4. **대기실 → 자동 시작**: 시작 10분 전부터 대기실에 들어갈 수 있어요. 시작 시간에 대기실에 있는 신청자끼리 4~6명씩 그룹이 되어 자동으로 시작해요. 인원이 모자라면 그 세션은 취소돼요.
5. **1:1 음성 로테이션**: 그룹 안에서 모두가 한 번씩 1:1로 음성 대화를 해요 (LiveKit).
6. **서로 선택**: 또 이야기하고 싶은 사람을 고르고, 서로 고른 경우에만 결과를 보여 줘요.

### 매칭 규칙
- **필수 조건(양방향)**: 머리 길이, 깁텍 범위·플라토닉, 문담피 허용 범위. 그룹 안의 **모든 쌍**이 서로의 조건을 만족해야 해요.
- **가산점(양방향)**: 원하는 상대 성향에 얼마나 가까운지. 이 점수가 높은 사람끼리 같은 그룹이 되도록 나눠요.
- 한 세션에 6명보다 많이 모이면 AI가 그룹을 나누고, 서버가 결과를 다시 검사해요. AI를 쓸 수 없으면 규칙 기반으로 나눠요.

## 디자인: 히로 스펙트럼

깁텍 성향을 사이트 색으로 씁니다. **플라토닉은 노랑**, **온텍은 분홍**에서 **중간은 보라**를 거쳐 **온깁은 파랑**이 됩니다. 색 값은 `src/lib/compat.ts`의 `SPECTRUM`과 `tgColor()`, 그리고 `src/app/globals.css`에 있어요.

## 실행

```bash
npm install
cp .env.example .env.local   # 키를 채우세요 (비워 둬도 동작)
npm run dev
```

- 사용자 화면: http://localhost:3000
- 운영자 화면: http://localhost:3000/admin
  - 혼자 테스트하기: **데모 참가자 10명 추가** → 라운드 길이를 고르고 **2분 뒤 시작하는 테스트 세션 열기**
  - 사용자 화면의 테마 게시판에서 그 세션을 신청하고 **대기실 입장**을 누르세요. 2분 뒤 자동으로 시작돼요. 기다리기 싫으면 운영자 화면에서 **지금 바로 시작**을 누르면 돼요.

여러 사람이 같이 시험하려면 서로 다른 브라우저(또는 시크릿 창)로 접속하세요. 사용자는 쿠키로 구분합니다.

## 키가 없을 때

| 기능 | 키 있음 | 키 없음 |
|---|---|---|
| 성향 분석, 테마 목록, 큰 세션 그룹 나누기 | Claude (`ANTHROPIC_API_KEY`) | 규칙 기반 대체 로직 |
| 1:1 음성 대화 | LiveKit | 타이머와 화면 흐름만 진행 |

Claude 호출이 실패하거나 결과가 이상해도(없는 id, 중복 배정, 인원 초과 등) 서버가 검증하고, 필요하면 규칙 기반 로직으로 대체합니다.

## 구조

```
src/lib/ai.ts          Claude 연동 (구조화 출력 + 서버 측 대체 모델)
src/lib/compat.ts      만남 성향, 원하는 상대 조건, 양방향 궁합 판정, 스펙트럼 색
src/lib/heuristics.ts  규칙 기반 대체 로직, 성향 점수 계산
src/lib/rotation.ts    1:1 로테이션 일정, 현재 라운드 계산
src/lib/questions.ts   검사 문항과 태그 목록
src/lib/store.ts       저장소 (메모리 + .data/hiro-db.json)
src/lib/server.ts      쿠키 사용자, LiveKit 토큰, 화면용 상태
src/app/api/*          API
src/app/{start,quiz,me,lobby,room,admin}  화면
```

## 정식 서비스 전에 할 일

- **본인인증**(PASS 등)으로 여성·성인 확인. 지금은 체크박스로만 확인해요.
- **DB 교체**: 지금은 서버 한 대의 JSON 파일에 저장해요. Postgres(Supabase 등)로 바꿔야 해요.
- **로그인**(카카오/애플), 신고·차단, 대화 중 비상 종료 버튼.
- 서로 선택한 뒤의 **1:1 채팅**.
- 세션 시작 알림(푸시·문자). 지금은 사용자가 직접 대기실에 들어와야 해요.
